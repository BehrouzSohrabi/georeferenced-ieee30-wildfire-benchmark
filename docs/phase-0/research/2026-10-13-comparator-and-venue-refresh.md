# Comparator and venue refresh — 13 October 2026

## Comparator positioning

The Phase 0 evidence supports a bounded differentiation claim: no reviewed comparator was found that combines a compact IEEE-style electrical benchmark, explicit project-released georeferenced branch routes, a documented wildfire-scenario interface, and reproducible spatial/fire/grid workflow outputs in one package. This is a targeted reconnaissance finding, not a universal novelty claim.

| Comparator | Relevance | Release/metadata note |
|---|---|---|
| CATS — Taylor et al. (2024), DOI <https://doi.org/10.1109/TEMPR.2023.3338568> | Synthetic California-georeferenced system with bus coordinates and GeoJSON routes | BSD-3-Clause reported by the checked project resources. |
| RTS-GMLC | Synthetic 73-bus benchmark with node coordinates | Check current data-use terms before relying on or redistributing any payload; explicit released line polylines were not verified in this review. |
| Taylor & Roald (2022), DOI <https://doi.org/10.1016/j.epsr.2022.108592> | Wildfire-risk framework / comparison context | Cite as related method evidence, not as a project-owned component. |
| PowerLine-WildfireRisk-Data | Daily wildfire-risk data for RTS-GMLC and California lines | Treat as external comparison material; verify payload/license/version before reuse. |

## Provisional data-descriptor venues

1. **Scientific Data — Data Descriptor:** requires a compliant repository, persistent identifier, and public access no later than the second review round. The project must re-check current author instructions and data-license compatibility immediately before submission.
2. **Data in Brief:** requires public repository data with a globally unique persistent identifier and downloadable data or a documented data-use agreement.

## Remaining Phase 0 action

Before deciding a venue, map the actual v1.0.0 release scope and license to the chosen venue's current requirements. Do not claim eligibility based on this screening alone.
