## Clearance rule

No upstream item becomes releasable merely because a related tool, article, or dataset has a permissive license. The clearance package for each prospective bundled item must record: exact product/version, official source URL, access date, applicable terms, attribution text, modification statement, reviewer, decision, and evidence location.

**Operational deadline:** 2026-10-25. Any extension requires a dated decision-log entry.
